# Frostbound Frontier

**Requires regular SuperTux 0.7.0.** Download it from https://www.supertux.org/download. SuperTux 0.6.3 is unsupported. No custom executable, compilation, or separate asset pack is needed.

Ten snowy adventures featuring Ember Beetles, Spring Toads, Crystal Crabs, Snow Wisps, and two-stomp Armored Snails. The first five stages introduce the creatures; the later stages combine them.

## Install

Download `frostbound_frontier.zip`, keep it zipped, and open **Add-ons → Install from file** in SuperTux 0.7.0. Drag the archive onto that screen. Return to **Contrib Levels → User Contrib Levels → Frostbound Frontier**. Enable the add-on if needed.

Enter through Contrib Levels to save worldmap progress. Finish each stage to unlock the next road.

## Portable custom features

The ZIP includes the artwork, tilesets, and Squirrel scripts required by this world. Native game assets are provided by SuperTux 0.7.0. Scripted creatures keep their principal patrol, hop, flight, armor, and revival behaviors. Native trampoline physics provide the bounce objects; hold Jump for a stronger bounce.

Compared with the old custom-engine prototype, bounce heights use native values, armor/freeze feedback flashes rather than tinting, and scripted fire/ice interactions are an approximation. Single-player is the supported mode. See the project README for details.
