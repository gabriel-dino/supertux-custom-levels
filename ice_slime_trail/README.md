# IceSlime Trail

**Requires regular SuperTux 0.7.0.** Download it from https://www.supertux.org/download. SuperTux 0.6.3 is unsupported. No custom executable, compilation, or separate asset pack is needed.

Five snowy adventures introducing animated IceSlimes, icy ground, checkpoints, optional Tux Dolls, and igloo exits. IceSlimes retain native enemy collision and stomp behavior.

## Install

Download `ice_slime_trail.zip`, keep it zipped, and open **Add-ons → Install from file** in SuperTux 0.7.0. Drag the archive onto that screen. Return to **Contrib Levels → User Contrib Levels → IceSlime Trail**. Enable the add-on if needed.

Enter through Contrib Levels to save worldmap progress. Finish each stage to unlock the next road.

## Levels

- First Frost
- Slippery Business
- Crystal Stairway
- Moonlit Crossing
- The Frozen Gauntlet

## Portable custom features

The ZIP includes the artwork and tilesets required by this world. Native game assets are provided by SuperTux 0.7.0. IceSlimes use the standard snowball behavior with their own animated sprite.

This world uses native enemy behavior and its original layouts. See the project README for installation and supported-version details.
